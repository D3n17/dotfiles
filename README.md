# Dotfiles
This is a personal repository with my configuration files for hyprland, kitty, nvim, rofi, waybar on ArchLinux.

This command might install all things you need for this config to work:

```bash
sudo pacman -Syu --needed \
    hyprland waybar \
    hyprpolkitagent \
    slurp grim swappy wl-clipboard \
    blueman bluez bluez-utils network-manager-applet \
    pavucontrol pipewire wireplumber \
    hypridle hyprlock hyprpaper hyprsunset \
    swaync kitty dolphin \
    brightnessctl playerctl \
    xdg-desktop-portal-hyprland nwg-look
```
